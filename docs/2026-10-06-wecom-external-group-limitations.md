# WeCom 外部联系人群能力核对

日期：2026-10-06。结论：企微官方资料描述了 API 模式智能机器人在群里接收 `@` 消息，但没有明确承诺它可加入含个人微信客户的外部联系人群；必须用本企业租户实测，因此目前不能宣称已实现“个人微信客户 + 客服 + OverTree 同群对话”。

> 更新：Gateway `0.1.9` 已部署。代码和生产底座已准备好，群通道仍保持关闭，等待真实租户测试。

## 目标与现有通道边界

| 能力 | 官方通道 | 当前判断 |
| --- | --- | --- |
| 个人微信用户直接咨询 OverTree | 微信客服账号 + 微信客服 API | 支持一对一咨询；需要企业启用 API、配置回调，并由 API 管理客服账号。 |
| 企业员工在内部群 @OverTree | 企业微信 API 模式智能机器人长连接 | 支持机器人可进入的群聊；Gateway 当前作为默认关闭的群聊 POC。 |
| 个人微信客户、客服员工、OverTree 在同一外部群互动 | 企业微信 API 模式智能机器人 | 未确认。机器人 API/长连接和群聊 @ 能力已开放，但公开资料未明确说明可加入含个人微信客户的外部群。 |

企业微信 5.0.10 的客户端更新说明新增 API 模式智能机器人，可配置回调接收用户提问和发送回复；腾讯云在 2026-08 更新的接入指南说明可以用 WebSocket 长连接，并演示在群里 @ 机器人。这种长连接不需要机器人回调域名。另一方面，企微智能机器人 FAQ 的公开版本仍说明仅支持内部群，且更新后的接入指南没有明确说外部联系人群也开放。基于这两组资料，群类型范围仍需在管理员测试租户实测，不能只凭“支持群聊”认定客户群可用。

Gateway `0.1.9` 的群适配支持把图片、文件、视频保存到绑定项目；语音使用企微回传的转写文本。媒体以流方式下载并受 `WECHAT_MAX_MEDIA_BYTES` 限制，默认上限 20 MiB；超限附件不入库，同一消息的文字问题仍可继续处理。群内输入继续写入该客户已授权的 OverTree 项目和会话，项目生成文件只会在绑定时选择分享后，以短时限下载链接发回群里。

## 为什么其它公开 API 不构成同群对话方案

- 微信客服是用户与客服账号的一对一咨询通道，不是可加入微信群的群成员。
- 客户群详情 API 可以读取群资料和成员，不等于开放群消息实时回调。
- 企业群发 API 用于通知员工确认后向客户或客户群发送群发内容，属于受频控的运营触达，不是收到每条 `@OverTree` 后即时回复的机器人 API。
- 会话内容存档涉及企业成员范围配置和外部联系人同意等前提；它提供留存/审计能力，不能因此推导出官方允许一个机器人账号加入外部联系人群并实时发言。
- 把个人微信桌面端自动化、抓包、Hook 或非官方协议接进来会重新引入用户明确希望避免的账号与合规风险，因此不作为该功能的替代实现。

## 对现有代码的处理

- 保留微信客服私聊链路：Cloud 登录用户生成一次性绑定码；个人微信从官方客服入口发来绑定码；后续消息继续进入绑定项目的 OverTree 会话；消息、附件和结果链接沿用 Cloud 的存储与权限边界。
- 保留 API 模式 Smart Bot 适配器作为默认关闭的群聊 POC。新增的安全录入脚本可以在服务器记录 Bot ID/Secret，但不会启用、重启或连接机器人；只有管理员确认可以将该机器人加进含个人微信用户的测试群后，才继续验收目标群流程。
- Cloud 微信连接页与 Gateway 文档提示外部联系人群范围尚未验收；绑定前先在企业测试群确认成员可见与双向消息。
- 群机器人仍默认关闭；私聊与群聊保持独立开关。

## 私聊接入仍待企业管理员验收

微信客服 API 文档说明，管理员需在“微信客服应用”开启 API 并填写回调配置，然后查看 API Secret；启用后才能通过 API 管理客服账号和处理消息。当前生产 `wechat.overtree.top` 已具备 HTTPS，但企业微信曾因域名主体校验拒绝该 URL。DNS、TLS 和域名所有权校验不能代替企业微信的备案主体审核。

`kf/sync_msg` 文档允许不传短效回调 token，但企业启用微信客服 API 的流程仍要求先配置并通过回调 URL。轮询限制和目标租户是否允许无 Token 降级，也需要在管理员凭证可用后验证，不能据此声称已绕过域名审核。

## 当前生产状态

- 生产 Cloud `0.1.21`、Gateway `0.1.9` 保持健康；公网健康检查均返回 HTTP 200。
- `WECHAT_ENABLED=false`、`WECHAT_GROUP_BOT_ENABLED=false`；线上健康接口显示两个通道均关闭。
- Cloud 40 项测试、Gateway 27 项测试和两边静态检查通过。
- Gateway 镜像已包含预检脚本；生产主机没有 Node 依赖时，脚本会通过容器执行，并在凭证缺失时安全停止。
- 尚未完成企业微信真实租户的回调校验、API Secret / `open_kfid` 安全录入、微信用户绑定、附件收发及 Agent 回复验收。
